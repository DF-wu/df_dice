# dice recorder
過年大戰紀錄骰子的小工具

特別感謝 @stanley2058 為本專案做出的貢獻。

## 功能

### 記錄
- 逐筆記錄骰子點數（每局三顆），自動分局並標記進行中的局
- 鍵盤快捷鍵：`1`–`6` 直接記錄點數、`Backspace` 撤銷最新一筆
- 撤銷最新一筆記錄（Undo Last）並同步更新所有統計
- Reset 清空目前對局紀錄（不影響其他對局）
- 每一筆自動記下時間戳，紀錄與偏好（分頁、篩選、主題）保存於瀏覽器
- 可建立、切換、重新命名與刪除對局；每個對局分別保留完成局及進行中的骰點

### 統計面板（五個分頁）
- **總覽**：總骰數、完成局數、平均和值、中位數、標準差、大小連續、牌路型態（偏連/偏跳）、遊戲時長；大小/豹子與單雙分佈（附理論機率標線與偏差）；大小路單（珠盤路）；和值走勢折線圖
- **骰面**：各骰面次數與機率（對照 1/6 理論值與偏差）、熱門/冷門骰、卡方公平性檢定、每局第 N 顆骰的位置分佈熱圖、同局共現矩陣、各骰面遺漏局數
- **和值**：3–18 和值長條圖（疊加理論期望次數）、和值區間（3-6 / 7-10 / 11-14 / 15-18）、最常與最少開出的和值、最高/最低和值與其局號、各和值遺漏局數
- **型態**：對子 / 豹子 / 順子統計與理論值對照、各點數圍骰分佈、特殊型態遺漏、各點數每局出現 0–3 顆與至少兩顆的次數、不分順序的熱門組合、三顆相異局數
- **趨勢**：最長大連/小連/單連/雙連、大小轉折次數與轉折率、5 局移動平均線、最近 12 局明細表

### 對局紀錄
- 每局顯示點數、和值、大小、單雙、對子、順子與完成時間
- 與上一局的和值差；可刪除指定局並同步更新統計
- 依全部 / 大 / 小 / 豹子 / 對子 / 順子 / 單 / 雙 篩選，並顯示各條件的局數

### 五套 UI 風格
右上角可即時切換，選擇會保存於瀏覽器：

| 風格 | 說明 |
| --- | --- |
| 賭城夜（預設） | 深藍紫底 + 金色標題的賭場風 |
| 新春紅金 | 過年氣氛的紅底金字 |
| 霓虹 | 青藍 / 洋紅的賽博龐克配色 |
| 日光 | 明亮乾淨的淺色介面 |
| 紙墨 | 溫暖的米色紙感、低彩度 |

全部風格都只由 CSS 變數定義，要新增一套只需在 `index.html` 增加一組 token 並在 `src/themes.js` 註冊。

### 其他
- JSON 匯出所有對局、目前選取的對局與未完成紀錄；CSV 匯出目前對局（含未完成局及正確引號處理的對局名稱），也可複製統計摘要
- JSON 匯入支援新版完整備份、舊版 v2 備份與單一對局，以及 `first/second/third`、`rolls/at` 歷史陣列；不支援 CSV 匯入
- 匯入前完整驗證，任何不合法紀錄都拒絕整份檔案，原有對局不變。成功後保留兩邊的未完成紀錄並選取匯入備份原本的對局，碰撞的 ID 會重新分配
- 舊資料遷移保留原始來源與 `_backup` 副本；若讀取或遷移儲存失敗，阻止覆寫，請先從瀏覽器儲存空間備份原始資料再處理
- 單雙為和值的描述統計，包含豹子；大小不含豹子；「對子」為恰有兩顆相同，「至少兩顆」包含豹子

## 專案結構
```
src/
  history.js  紀錄資料結構、正規化、新增/撤銷、時間戳
  round.js    單局判定（大小、單雙、對子、豹子、順子）
  theory.js   216 種組合的理論機率表
  stats.js    完整統計計算
  charts.js   量表、長條圖、折線圖、熱圖、路單的 HTML 產生器
  themes.js   UI 風格清單與驗證
  format.js   數值與標籤格式化
  render.js   統計面板與對局紀錄的畫面組裝
  export.js   JSON / CSV / 摘要匯出
  sessions.js 對局資料、備份驗證、匯入合併與安全遷移
  app.js      事件綁定、狀態與儲存
  main.js     進入點
```

## GitHub Pages 部署
本專案是純靜態頁面，`index.html` 直接載入 `src/main.js`，不需要額外 web server 或打包流程。

## 測試
```bash
npm install
npm test
```

`npm test` 會執行 Vitest 並驗證 coverage 門檻（statements / branches / functions / lines 皆為 100%）。
